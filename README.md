# normkompass-mcp

A small [MCP](https://modelcontextprotocol.io) server in Python that lets an AI agent search German federal law
and ask cited questions through [normkompass](https://github.com/sotream/normkompass).

**Status: in development.** Nothing is implemented yet; the first change is a specification (see
`openspec/changes/`). This page will describe only what exists and has been run.

Not legal advice.
